# Heart Attack Risk Analysis Dashboard

## 📌 Project Overview
The **Heart Attack Risk Analysis Dashboard** is an interactive data visualization project developed to analyze patient health records and identify heart attack risk patterns.  
The dashboard provides meaningful insights into patient demographics, cholesterol levels, blood pressure levels, age groups, gender distribution, and overall risk categories.

This project helps users:
- Monitor heart attack cases efficiently
- Identify high-risk patient groups
- Analyze health trends visually
- Support healthcare decision-making using data analytics

---

# 📊 Dashboard Features

## 🔹 Main Dashboard
The main dashboard provides a summarized overview of patient and heart attack statistics including:

- Total number of patients
- Heart attack percentage
- Total heart attack cases
- Average patient age
- High-risk patient count

### 📈 Visualizations Included
- Heart Attack Cases by Age Group
- Heart Attack Cases by Risk Category
- Heart Attack Cases by Gender
- Heart Attack Cases by Cholesterol Level
- Total Patients by Blood Pressure Level

---

## 🔹 Detailed Risk Analysis Dashboard
The detailed dashboard allows deeper analysis using interactive filters and charts.

### 🎯 Interactive Filters
Users can filter data based on:
- Gender
- Age Group
- Risk Category
- Blood Pressure Level

### 📊 Additional Insights
- Heart attack distribution by gender
- Risk category comparison
- Patient summary table
- Dynamic filtering for better analysis
